# Chrome Web Store assets

Everything you need to submit Respite for review:

1. Follow **[LISTING.md](./LISTING.md)** (copy, privacy answers, test steps)
2. Upload graphics from `icons/`, `screenshots/`, and optionally `promo/`
3. Use privacy policy: https://danish-ali-malik.github.io/respite/privacy.html
4. Upload a zip of the repo’s `dist/` folder contents

You create the developer account ($5 one-time) and click submit when ready.
